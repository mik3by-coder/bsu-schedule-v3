# BSU Schedule · 614 (English)

Веб-приложение расписания для группы **614 (Engl)** Института бизнеса БГУ.

## Что изменилось в v3.1

- Таймер больше не ведёт отсчёт по несуществующим парам после окончания учебного дня.
- После последней пары сегодня таймер считает до ближайшего реального занятия следующего дня по данным БГУ.
- В паузах таймер показывает перерыв только тогда, когда следующая реальная пара действительно начинается в конце этого перерыва.
- Для стандартных стартов длительность пары учитывает обе 40-минутные части и 5-минутный внутренний перерыв.

## Что изменилось в v3.0

- источник расписания заменён на официальный URL группы 614:
  `https://sb.bsu.by/raspisanie/map-614__engl_.xml`
- расписание загружается с БГУ автоматически при запуске сервера и обновляется каждые 5 минут;
- названия дисциплин, преподаватели, аудитории и подгруппы берутся напрямую из таблицы БГУ;
- заголовок группы также читается с официальной страницы;
- исправлена сетка дней: дни разнесены и отображаются как отдельные карточки;
- правый блок упорядочен: режим → таймер → начало/конец перехода → текущее/следующее занятие → ближайшие занятия → режим учебных занятий;
- добавлен таймер по присланному «Режиму учебных занятий»;
- таймер показывает время до 5-минутного перерыва, до конца короткого/длинного перерыва, до начала следующей пары и завершение учебного дня;
- добавлена полная таблица режима 1–8 пар;
- мобильная версия переработана: 2 карточки дня в ряд, компактные карточки, большие кнопки и удобный таймер.

## Запуск локально

```powershell
npm.cmd install
node server.js
```

Открой `http://localhost:3000`.

## Синхронизация

Сервер запрашивает официальный источник БГУ напрямую. При ошибке сети прошлые данные используются из локального кэша, если он уже был сохранён после успешной синхронизации.

Переменная окружения `BSU_SOURCE_URL` позволяет при необходимости заменить источник.

## Важно про время окончания

Официальная таблица БГУ публикует время начала занятий. Для стандартных времён 08:30, 10:10, 12:05, 13:40, 15:15, 17:00, 18:35 и 20:10 конец занятия берётся из присланного режима учебных занятий. Для нестандартных стартов, например 09:30 или 11:00, используется резервная оценка 90 минут, потому что источник не содержит явного времени окончания.
